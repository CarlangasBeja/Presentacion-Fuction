⚡ FUNCTIONS EN BASES DE DATOS

Teoría completa + ejemplos interactivos

📌 ¿Qué es una FUNCTION?

Una FUNCTION en bases de datos es un bloque de código SQL que recibe datos, realiza cálculos y SIEMPRE devuelve un valor.

🎯 ¿Para qué se usa?

  • 💰 Cálculos automáticos (descuentos, IVA)
  • 📊 Promedios y estadísticas
  • 🧮 Transformación de datos
  • ⚙️ Reutilizar lógica SQL

⚡ Importancia

Permiten evitar repetir código SQL y hacen las consultas más eficientes y limpias. Son clave en sistemas bancarios, tiendas online y sistemas académicos.

👍 Ventajas

  • ✔ Reutilización de código
  • ✔ Automatización de cálculos
  • ✔ Mayor organización

👎 Desventajas

  • ✖ No modifican datos directamente
  • ✖ Pueden afectar rendimiento si son complejas

⚔️ FUNCTION vs PROCEDURE

FUNCTION PROCEDURE
Devuelve un valor No siempre devuelve valor
Se usa en SELECT No se usa en SELECT
Cálculos Acciones (INSERT/UPDATE)

💡 Ejemplo 1: Descuento

CREATE FUNCTION descuento(precio DECIMAL)
RETURNS DECIMAL
BEGIN
    RETURN precio - (precio * 0.10);
END;

💡 Ejemplo 2: IVA

CREATE FUNCTION iva(precio DECIMAL)
RETURNS DECIMAL
BEGIN
    RETURN precio + (precio * 0.12);
END;
